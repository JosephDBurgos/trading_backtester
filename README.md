# Backtrader C++

A personal project to learn C++ by building a simple backtesting framework for trading strategies.

## Goals
- Learn modern C++ (C++17+)
- Implement a modular backtesting engine
- Add strategies and performance metrics
- Visualize results later (CLI or GUI)

## Structure
- `src/`: source code
- `include/`: headers
- `data/`: sample price data
- `tests/`: test files

## Build
```bash
mkdir build && cd build
cmake ..
make
./backtrader
